# Rasul Game
Summer Godot Engine fun-project. Some assets were found online, some were created by myself.
This project aimed to use as many tools as I could, including basic shaders, simple UI and audio design (menu was created from scratch, as well as audio effects), and a ton of engine mechanics. 
## Features
- Music from **JoJo, Hunter × Hunter, Doom**
- Textures made from meme photos of my classmates
- It's just fun!
---
## Running
### Linux
1. Download files [THEGame.pck](THEGame.pck) and [THEGame.x86_64](THEGame.x86_64)
2. Make sure both files are in the same folder
3. Run **THEGame.x86_64**

### Windows
1. Download files [THEGame_win.pck](THEGame_win.pck) and [THEGame_win.exe](THEGame_win.exe)
2. Make sure both files are in the same folder
3. Run **THEGame_win.exe**
